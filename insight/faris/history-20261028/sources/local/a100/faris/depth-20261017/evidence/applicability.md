# Applicability and exclusions
Included: existing decision-safe source representations, fold-local preprocessing, feature removal contrasts, linear/spline models, LightGBM, CatBoost, XGBoost, expanded fixed training budgets, regularization, weighting, GPU execution and adaptive finite search. Source lineage and historical EDA are carried in selection/EDA artifacts.
Excluded: FM models (user earlier discouraged and short remaining window); new raw-history aggregations (previous 5,120 representations already explored); learned ensembles and seed/temporal checks (previous campaign already completing these); competition-test prediction/submission; newly reusing confirmation labels; external data; exact DFS/BFS (not a discrete optimization task); new deep architecture dependency installations (remaining time and no matched baseline); AMD GPU (toolkit allocates NVIDIA GPUs only, preserve validated CPU path on PC1).
Storage is a hard admission constraint; no model deletion. PC1/PC2 free disk about 12 GiB at probe; allocation below this leaves OS/earlier campaign room. New scheduler uses up to 16/12/12/16 CPU units on PC1/PC2/PC3/node380; actual cgroup quota and available RAM can lower admission. Previous verification workload retains its allocations. GPU jobs exclusive per physical GPU within new campaign; initial probe found both RTX cards free. CPU/RAM guards are sampled, not claims of kernel isolation. Managed node380 can still be stopped by its provider.
