# Loan-cluster credibility as a feature, predictive model fixed

The first50k-context-only diagnostic found conditional same-loan dependence: nested ANOVA ICC .20978 for >=1day and .17135 for >=30day delinquency. Borrower means were controlled. Median moment-based effective information was only .346/.393 of nominal installment counts. This is an approximate binary-ANOVA diagnostic, not a claim of true independent loan effects.

Hypothesis: the existing borrower propensity posterior overstates the information in repeated installments from the same loan. Keep the >=30day mature event set and its already fitted context-only Beta prior(alpha,beta) fixed. For each borrower, model p~Beta(alpha,beta), loan-specific p_l~Beta(kappa*p,kappa*(1-p)), and k_l|p_l~Binomial(n_l,p_l). Fix kappa=(1-rho)/rho using the original context-only nested ANOVA moments, estimated separately for the1day/30day flags. No default labels estimate kappa or the prior.
