# Supplied data and campaign boundaries

Metric: Logika tie-aware two-sample KS on class-1 probabilities, higher is better.
The original official evaluator source is not present; the repository evaluator is
checked independently against SciPy, including tied scores. Public scores remain
historical references rather than new CV measurements.

Use only the supplied application tables and their historical tables. Fit against
provided train targets only. The prediction-test table has no target. IDs are opaque
join keys and must not become predictors. Observe decision-time cutoffs, bureau
availability, completed account months, deduplicated completed-order spending,
and provider overlap. Cancelled basket values are separately named behavior.

No foundation-model search, external borrower data, hidden labels, RNG reconstruction,
paid compute, privileged package installs, Kaggle APIs, leaderboard calls, or competition
uploads/submissions. SSH deployment to the three approved PCs is part of this campaign.
No competition submission CSV is generated by this experiment system.

PC1: use available CPU/RAM with a 2 GiB OS reserve and verified AMD/OpenCL acceleration.
PC2 and PC3: aggregate 7 workers, 7 CPU-equivalents, 20 GiB RAM, and one 12 GiB GPU.
PC3 connections and transfers originate on PC2. New code and artifacts live under
~/faris/logika-meta-experiments/<campaign_id> on each host.

The only new SSH credential is a dedicated restricted PC2-to-PC1 campaign key,
explicitly approved by the user. Existing private keys are never copied.

Never power off or reboot any host. Only terminate this campaign's own processes
and its own isolated resource-test units. Existing workloads remain untouched.
