# Hypotheses and primary sources

The CANN principle embeds a classical prediction as a fixed offset and learns nonlinear corrections. The CPU experiment transfers that additive-logit idea to Bernoulli GLM plus LightGBM, with matched intercept-only and GLM-only controls. It is not an exact neural CANN reproduction or a claim of guaranteed ranking improvement. Sources: Wuthrich/Merz, EDITORIAL:YES,WE CANN!, DOI10.1017/asb.2018.42, published7December2018, https://doi.org/10.1017/asb.2018.42 ; Tzougas/Kutzkov, Enhancing Logistic Regression Using Neural Networks for Classification in Actuarial Learning,2023, https://www.mdpi.com/1999-4893/16/2/99 ; LightGBM4.6 init_score API https://lightgbm.readthedocs.io/en/v4.6.0/pythonapi/lightgbm.Dataset.html .

Case-control sampling motivates retaining minority default examples under a finite context budget. This is a context-distribution transfer hypothesis for a pretrained model, not logistic case-control invariance or a reproduction of local case-control sampling. Full-context class support is6790/6791positives per50k, so1:7would be infeasible and was rejected during preparation before any clock/fit; preregistered ratios are1:1,1:3,1:5. Natural-prevalence controls use exact same N, same views, same backend, checkpoint and internal estimator count. Sources: Fithian/Hastie, Local Case-Control Sampling,2014, https://arxiv.org/abs/1306.3706 ; original author PDF https://www.stat.berkeley.edu/~wfithian/papers/lcc.pdf ; pinned official foundation checkpoint/model card https://huggingface.co/nvidia/Kumo-Tabular . Noanalytic prior adjustment or query-dependent resampling is applied; the unchanged held-meta calibrator is the prespecified downstream comparison.
